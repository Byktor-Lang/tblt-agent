Ejercicio 1 — ¿Lógico o ilógico? (Ordena)

Read each statement. Decide: Logical (it makes sense in context) or Illogical (there is a clear semantic reason it does not work). Write each statement number in the correct column. Then write the reason for each illogical statement.

Statements:
1. El sábado por la mañana estoy ocupado porque tengo que estudiar para el examen.
2. El parque está libre los domingos por la tarde, así que voy allí.
3. Estoy libre este fin de semana porque tengo que ir al partido de fútbol.
4. Puedo ir al cine el domingo porque no tengo que hacer nada.
5. El lunes por la tarde estoy ocupado/a, así que puedo salir el sábado.
6. Tengo que estudiar el domingo por la mañana, entonces no puedo ir al parque.

Ejercicio 2 — ¿Cuál no corresponde? (Odd One Out)

In each group, circle the word that does NOT belong. Write a sentence in Spanish explaining why it is different.

Set A:

el cine el parque el partido de fútbol el domingo
"________ no corresponde porque ________________________."

Set B:

el sábado el domingo el fin de semana libre
"________ no corresponde porque ________________________."

Set C:

por la mañana por la tarde ocupado/a el sábado
"________ no corresponde porque ________________________."

Ejercicio 3 — Completa las frases (Sentence Frames)

Complete each sentence frame using words from the box and your own ideas. Each sentence must make personal sense for you.

Word bank: el sábado · el domingo · por la mañana · por la tarde · el cine · el parque · el partido de fútbol · libre · ocupado/a · el fin de semana

1. Using tener que + infinitivo — explain a constraint:

Este ________ por la ________ estoy ocupado/a porque tengo que ________________________.

2. Using poder + infinitivo — express availability:

El ________ por la ________ puedo ir a ________ porque estoy libre.

3. Combining both structures — express a compromise:

No puedo ir el ________ porque tengo que ________________, pero puedo ir el ________ por la ________.

4. Plan sentence — write your weekend plan:

El ________ [sábado/domingo] por la ________ [mañana/tarde] vamos a ________ porque ________________________.
